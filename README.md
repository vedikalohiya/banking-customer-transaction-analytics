# Customer Transaction Analytics & Insights — ICICI Bank

## Overview

An Azure-based analytics solution designed to consolidate and analyze
customer transaction data from multiple banking sources including
core banking, mobile applications, UPI, and ATM/POS systems.

## Architecture

Core Banking
      ↓
Mobile App
      ↓
UPI / ATM / POS
      ↓
Azure Data Factory
      ↓
ADLS Gen2
      ↓
Azure Synapse Analytics
      ↓
Power BI

## Technologies

- Azure Data Factory
- Azure Data Lake Storage Gen2
- Azure Synapse Analytics
- Azure Cosmos DB
- SQL
- Power BI

## Key Features

- Consolidated transaction data from 4 source systems
- Implemented parameterized ADF pipelines
- Supported incremental batch ingestion
- Performed ETL/ELT orchestration
- Integrated Azure SQL and Cosmos DB data
- Designed analytical data models
- Created Power BI dashboards for transaction analysis

## Dashboard Insights

The Power BI dashboard provides insights into:

- Customer spending patterns
- Transaction trends
- Peak transaction hours
- Transaction volumes
- Customer-level analysis
